# Changelog

## 1.0.0

- First release of Geomap Layers (`vericode-geomaplayers-panel`).
- Geomap panel with layer visibility legend (top-left), including basemap.
- Sync layer visibility from a dashboard variable / URL (combo → panels; legend does not write back).
- Preset values with `|` (e.g. `Principal (Usinas & Rotas) : Usinas|Rota`).
- Demo dashboard and Docker Compose for local Grafana.
- Panel options aligned with native Geomap; preserve options when switching between Geomap and Geomap Layers.
